Créer un projet et l’envoyer sur GitHub

Par un développeur passionné

Introduction

Voici un guide étape par étape pour créer un projet local, le versionner avec Git, puis l'envoyer sur GitHub.

Étapes complètes

1. Créer un dossier de projet

mkdir mon-projet
cd mon-projet
touch index.html

Crée ton fichier HTML de départ dans le dossier.

2. Initialiser Git

git init

Crée un dépôt Git dans ton dossier.

3. Ajouter les fichiers au suivi

git add .
(ou `git add index.html` pour un fichier spécifique)

4. Faire un premier commit

git commit -m "Premier commit : ajout du fichier index.html"

5. Créer un dépôt sur GitHub

Va sur github.com, clique sur New repository, entre un nom, puis clique sur Create repository.

6. Lier ton dépôt local à GitHub

git remote add origin https://github.com/ton-utilisateur/mon-projet.git

7. Pousser vers GitHub

git branch -M main
git push -u origin main

8. Travailler au quotidien

Après chaque modification :

git add .
git commit -m "Description"
git push

Fusion de branches avec Git (git merge)

1. Créer une branche secondaire

Travaille sur une fonctionnalité dans une autre branche :

git checkout -b ma-branche

2. Faire des modifications

Ajoute/modifie des fichiers, puis enregistre :

git add .
git commit -m "Travail dans ma-branche"

3. Revenir sur la branche principale

git checkout main

4. Fusionner la branche secondaire

Fusionne les changements de ma-branche dans main :

git merge ma-branche

✔️ S'il n'y a pas de conflit, la fusion est automatique.

5. Résoudre les conflits (si besoin)

Git t'indiquera les fichiers en conflit. Ouvre-les, choisis les bons morceaux de code, puis :

git add fichier_conflit.html
git commit

6. Pousser vers GitHub

git push origin main

Cloner un dépôt Git

1. Trouver l’URL du dépôt GitHub

Va sur la page GitHub du projet, clique sur Code puis copie l’URL HTTPS (exemple : https://github.com/utilisateur/projet.git).

2. Ouvrir un terminal et choisir le dossier

Place-toi dans le dossier où tu veux mettre le projet cloné :

cd chemin/vers/ton/dossier

3. Cloner le dépôt

Exécute la commande :

git clone https://github.com/utilisateur/projet.git

4. Aller dans le dossier cloné

Le dépôt est téléchargé dans un nouveau dossier :

cd projet

5. Travailler sur le projet

Tu peux maintenant modifier les fichiers, faire des commits, et pousser les changements.
